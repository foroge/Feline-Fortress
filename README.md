# Cat Tower Defense

Учебный игровой проект на **Python** с использованием библиотеки **Pygame**.

Проект представляет собой игру в жанре **Tower Defense**, где игрок защищает короля от волн зомби-котов, расставляя котов-защитников на игровом поле.

---

## Описание игры

На игровом поле автоматически генерируется маршрут, по которому движутся враги. Задача игрока — не дать зомби-котам дойти до короля и победить его.

Игрок может размещать котов-защитников на доступных клетках вокруг маршрута. За уничтожение врагов начисляются деньги, которые можно тратить на новых защитников. Также в игре есть отдельный кот, который генерирует деньги.

---

## Реализованная функциональность

- генерация маршрутов на игровом поле;
- три уровня сложности;
- случайное заполнение доступных клеток вокруг маршрута;
- размещение котов-защитников;
- движение врагов по маршруту;
- система денег;
- начисление денег за убийство врагов;
- отдельный юнит для генерации денег;
- главное меню;
- запуск игрового процесса;
- экран статистики;
- сохранение статистики в базу данных;
- хранение текущего пользователя в JSON-файле.

---

## Игровой процесс

1. Игрок запускает игру и попадает в главное меню.
2. Выбирает режим или уровень сложности.
3. На поле генерируется маршрут для врагов.
4. Игрок расставляет котов-защитников на доступных местах.
5. Зомби-коты двигаются по маршруту к королю.
6. За уничтожение врагов игрок получает деньги.
7. Цель — не дать врагам дойти до короля.
